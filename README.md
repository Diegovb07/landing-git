\# Mi Proyecto



Este repositorio contiene mis prácticas del curso de Git y GitHub.



\## Contenidos



\- Uso de repositorios locales.

\- Registro de cambios mediante commits.

\- Creación y manejo de ramas.

\- Trabajo con GitHub.



\## Objetivo



Aprender a gestionar proyectos y llevar un control de sus versiones utilizando Git y GitHub.
